# Quintal dos Pets 🐾

Este é o protótipo da interface de autenticação para o portal **QuintaldosPets**. O projeto consiste em uma tela de login responsiva e interativa desenvolvida puramente com tecnologias front-end para ser hospedada diretamente no GitHub Pages.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página de login.
*   **CSS3:** Estilização responsiva, design limpo e feedback visual (cores de erro e sucesso).
*   **JavaScript (Vanilla):** Interceptação do formulário, prevenção de recarregamento da página e simulação de validação de credenciais.

## ⚠️ Aviso de Segurança (Mockup)

Este repositório contém uma **Prova de Conceito (PoC) Visual**. A validação de usuário e senha está sendo feita no lado do cliente (via JavaScript) exclusivamente para fins de demonstração de interface e fluxo de navegação. 

**Em um ambiente de produção real:**
1. Credenciais nunca devem ser validadas ou armazenadas no código-fonte do front-end (JavaScript).
2. A autenticação deve ser gerida por um Back-end seguro ou por um Provedor de Identidade (IdP), como Firebase Authentication, Auth0 ou AWS Cognito.
